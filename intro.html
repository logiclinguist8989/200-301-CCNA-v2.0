How to use this guide

This guide follows the official CCNA 200-301 v2.0 exam topics you uploaded, domain by domain, and every chapter names the objectives it covers. Read Part 0 once, then work through the chapters in order with Packet Tracer open.

What each chapter contains: learning objectives, a plain-English introduction, the technical detail, how it works internally, real examples, diagrams, Cisco IOS configuration, verification, troubleshooting, an exam-focused summary, and original practice questions with explained answers.

R1# Privileged EXEC mode (show, debug, copy, reload)

Part 0.1 — Syllabus analysis: exam facts and domain structure

CCNA 200-301 v2.0 is a 120-minute exam with 5 domains, 29 numbered objectives and 30 lettered sub-objectives; half the weight sits in Domains 1 and 2. Cisco's first testing date for v2.0 is 3 February 2027 (Cisco Press); until then the v1.1 exam is the one being delivered, under the same 200-301 code.

Facts stated in the official document you uploaded

  • Exam title: Implementing and Administering Cisco Solutions (200-301 CCNA) v2.0. Passing it earns the CCNA certification.
  • Duration: 120 minutes.
  • You may have to evaluate output and recommendations from agentic AI and digital network assistants during troubleshooting. This is new and shapes how Domain 5 is taught here.
  • The topics are a "general guide"; related topics may appear, and Cisco can change the list without notice.
  • The document does not state the number of questions, the question types or the passing score. This guide will not invent them. Check Cisco's exam page close to your booking date.

Domain structure and official weightings

Domain Official weight Objectives Sub-objectives What dominates
1.0 Network Infrastructure and Connectivity 25% 1.1–1.7 (7) 1.5.a–d (4) Troubleshooting addressing, cabling, clients, DHCP

Readability check. All three pages of the uploaded PDF were readable; no objective is missing or cut off. One wording note: objective 5.3 prints "controllerbased" as one word; this guide reads it as "controller-based".

Sources: the uploaded 200-301 CCNA v2.0 Exam Topics PDF; Cisco Press certification updates for the first testing date.

v1.1 topics that v2.0 no longer names. These appear in older videos. They are not listed objectives, but Cisco says related topics may appear, so this guide treats them as background, briefly, where they support a listed objective:

  • Network topology architectures (two-tier, three-tier, spine-leaf, SOHO, WAN) and TCP vs UDP — kept as prerequisites in Chapter 1.
  • Cisco wireless architectures, AP modes and WLC GUI configuration — touched only where 2.2.b and 1.5 need them.
  • NTP — explained briefly in Chapter 25 because syslog timestamps depend on it.
  • QoS per-hop behaviour, TFTP/FTP, security program elements, password policy theory — not taught beyond a sentence.
  • REST APIs, JSON, Puppet and Chef, SDN planes — REST and JSON are explained only as far as controllers, cloud management and Ansible need them (Chapter 26). You asked for JSON and REST examples; v2.0 does not list them by name, so they are marked as supporting material.

One cross-cutting requirement. The exam description says you may need to evaluate output and recommendations from agentic AI and digital network assistants. From Chapter 10 onward, practice sets include an "AI assistant says…" question where you judge whether a suggested fix is correct.

Part 0.3 — Prerequisites, practical skills and study sequence

You need only basic computer skills and binary arithmetic to start; everything else is taught in order, and each phase below ends with a lab you can build in Packet Tracer.

Prerequisite knowledge (check yourself before Chapter 1)

  • [ ] Convert numbers between decimal and binary up to 255 (Chapter 2 revises this, but practise early)
  • [ ] Know what a file, a folder, an IP address and a web browser are in everyday terms
  • [ ] Open a command prompt on Windows (cmd or PowerShell) and a terminal on Linux
  • [ ] Install Cisco Packet Tracer (free with a Cisco Networking Academy account; use the newest version offered)
  • [ ] Install Wireshark on your laptop, to see real packets
  • [ ] Optional but useful: a Linux virtual machine (for example Ubuntu in VirtualBox) for Chapters 4, 17 and 26

Recommended study sequence for a beginner

The chapters are numbered in the order you should study them, which is not the order of the syllabus. Each phase depends on the one before it.

  1. Foundations (Chapters 1–4): how networks move data, cables and interfaces, IPv4 subnetting, IPv6, virtualization. Subnetting gets the most time here; expect to practise it daily for two weeks.
  2. Switching (Chapters 5–9): VLANs, trunks, SVIs, EtherChannel, edge ports, CDP/LLDP, Rapid PVST+. You build one campus topology and keep extending it.
  3. Routing (Chapters 10–13): routing tables, static routes, OSPFv2/OSPFv3, HSRP/VRRP. The campus now connects to a WAN.
  4. Services and troubleshooting (Chapters 14–17): DHCP, the troubleshooting toolkit, wireless principles, client troubleshooting on three operating systems.
  5. Security (Chapters 18–24): device access and AAA, secure file transfer, ACLs, NAT/PAT, DNS, Layer 2 security, IPsec VPNs.
  6. Operations and AI (Chapters 25–27): syslog, SNMP, management models, Ansible, agentic AI and prompting.
  7. Final review (Chapter 28): mixed-domain questions, integrated troubleshooting scenarios, command reference and weak-topic check.

A realistic pace for a student with classes is one chapter a week for the long chapters (2, 5, 9, 12, 20, 21, 23) and two a week for the short ones, about 18–20 weeks in total. Your first v2.0 exam date can be no earlier than 3 February 2027.
